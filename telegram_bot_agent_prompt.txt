AI METADATA GENERATION
================================================================================
Use the Groq SDK to generate metadata. Model: llama-3.1-8b-instant.

    from groq import Groq

    client = Groq(api_key=os.getenv("GROQ_API_KEY"))

    prompt = f"""Generate YouTube metadata for this video:
Platform: {platform}
Original title: {title}
Description: {description}
Duration: {duration}s

Return a JSON object with exactly these keys:
- title: engaging YouTube title with emojis, max 90 characters
- description: SEO-optimized description
- tags: array of strings, no # symbol, max 30 items

Respond with ONLY valid JSON. No markdown, no explanation."""

    response = client.chat.completions.create(
        model="llama-3.1-8b-instant",
        messages=[
            {
                "role": "system",
                "content": "You are a YouTube SEO expert. Respond only with valid JSON, no markdown."
            },
            {
                "role": "user",
                "content": prompt
            }
        ],
        temperature=0.7,
        max_tokens=1000,
    )

    raw = response.choices[0].message.content.strip()
    # Strip markdown fences if present
    cleaned = raw.replace("```json", "").replace("```", "").strip()
    metadata = json.loads(cleaned)

If GROQ_API_KEY is not set or the call fails, fall back to original yt-dlp
title/description/tags silently. Note in the confirmation message:
"(AI unavailable — using original metadata)"

================================================================================
BOT FLOW
================================================================================

STEP 1 — User sends a URL
- Bot validates it's a supported platform (reuse detect_platform from utils.py)
- Bot replies: "⬇️ Downloading..."
- Calls download logic directly (import and call the same yt-dlp code used in
  routers/download.py — extract into a shared function if needed)
- On success: bot sends the thumbnail image + a metadata preview message:

    📹 *Title:* {original_title}
    🌐 *Platform:* {platform}
    ⏱ *Duration:* {duration}s

    ✨ Generating AI metadata...

- Then calls Groq to generate metadata as described above.
- After AI generation, bot sends confirmation message:

    ✅ *Ready to upload*

    📝 *Title:* {ai_title}
    📄 *Description:* {ai_desc[:100]}...
    🏷 *Tags:* {', '.join(tags[:5])}
    🔒 *Privacy:* {default_privacy}
    💧 *Watermark:* {watermark or 'none'}

    Reply with:
    /upload — upload now
    /title New Title Here — change title
    /desc New description — change description
    /tags tag1, tag2, tag3 — change tags
    /privacy public|unlisted|private — change privacy
    /cancel — cancel

STEP 2 — User confirms or edits
- /upload → proceeds to upload
- /title <text> → updates pending title, re-shows confirmation
- /desc <text> → updates pending description, re-shows confirmation
- /tags <csv> → updates pending tags, re-shows confirmation
- /privacy <value> → updates pending privacy, re-shows confirmation
- /cancel → clears pending state, replies "❌ Cancelled."

STEP 3 — Upload
- Bot replies: "⬆️ Uploading to YouTube..."
- If TELEGRAM_WATERMARK is set, apply watermark using existing edit logic
  (drawtext bottom-right, fontsize 28, white with alpha)
- Call existing YouTube upload logic directly
- On success: bot replies:

    🎉 *Uploaded!*

    📺 {youtube_url}
    📊 Check analytics in 48h with /stats {history_id}

STEP 4 — /stats {history_id}
- Calls existing analytics logic
- Bot replies:

    📊 *Stats for "{title}"*

    👁 {views} views
    👍 {likes} likes
    💬 {comments} comments

INTEGRATION WITH main.py
================================================================================

In backend/main.py, update the lifespan context manager:

    from telegram_bot import start_telegram_bot, stop_telegram_bot

    @asynccontextmanager
    async def lifespan(_: FastAPI):
        init_db()
        await start_telegram_bot()   # no-op if BOT_TOKEN not set
        yield
        await stop_telegram_bot()

In telegram_bot.py, implement:

    _app = None  # global Application instance

    async def start_telegram_bot():
        token = os.getenv("TELEGRAM_BOT_TOKEN")
        if not token:
            logger.warning("TELEGRAM_BOT_TOKEN not set — bot disabled.")
            return
        import asyncio
        asyncio.create_task(_run_bot(token))

    async def stop_telegram_bot():
        global _app
        if _app:
            await _app.stop()
            await _app.shutdown()
